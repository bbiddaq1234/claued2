# 네이버 블로그 자동 발행

관심 있는 분야를 한 단어로 넣으면, AI가 요즘 뜨는 뉴스·인기 블로그 글을 모아 글감을 찾고,
자연스러운 글을 쓰고, 어울리는 사진까지 구해서 **네이버 블로그 에디터에 직접 타이핑해 발행**까지
끝내주는 프로그램입니다. 내 컴퓨터에서만 돌아가고, 아무 데도 나가지 않습니다(네이버·구글
검색, 그리고 AI 사진을 쓸 때만 Cloudflare에 접속합니다).

이 문서는 개발을 전혀 모르는 분도 따라 할 수 있게 썼습니다. **위에서부터 순서대로만 하시면 됩니다.**

---

## 0. 시작하기 전에 — 준비물 확인 (30초)

두 가지만 있으면 됩니다.

1. **명령어를 입력하는 창**을 열어주세요.
   - 맥: `Command + 스페이스` → "터미널" 입력 → 엔터
   - 윈도우: 시작 버튼 → "터미널" 입력 → 엔터
2. 아래를 그대로 붙여넣고 엔터를 눌러주세요.
   ```bash
   node --version && claude --version
   ```
   숫자가 두 줄 나오면 준비 끝입니다.

**숫자가 안 나오고 에러가 났다면:**

- `node`가 없다는 에러 → [nodejs.org](https://nodejs.org)에서 "LTS"라고 적힌 버전을 받아 설치하세요.
- `claude`가 없다는 에러 → Claude Code(이 프로그램을 실행하는 AI 도구)가 설치되어 있어야 합니다.
  설치가 안 되어 있다면 `npm install -g @anthropic-ai/claude-code`를 실행한 뒤, `claude`라고
  입력해 로그인하세요(구독 중인 Claude 요금제 계정으로 로그인하면 됩니다 — 이 앱은 그 구독을
  그대로 씁니다. 별도로 API 요금이 청구되지 않습니다).

---

## 1. 필요한 프로그램 내려받기 + 앱 켜기

같은 창에 아래를 한 줄씩 붙여넣고 엔터를 누르세요. (이 폴더 안에서 실행해야 합니다.)

```bash
npm install
npm run dev
```

`npm install`은 몇 분 걸릴 수 있습니다. 끝나고 `npm run dev`를 실행하면 잠시 뒤
`Local: http://localhost:4123` 같은 줄이 나옵니다. 그러면 브라우저에서
**http://localhost:4123** 을 열어주세요.

검은 배경에 위쪽이 초록색인 화면이 뜨면 성공입니다.

> ⚠️ 이 명령어를 입력한 창은 **켜둔 채로** 두세요. 닫으면 앱이 꺼집니다.
> 앱을 끄고 싶으면 그 창에서 `Ctrl + C`를 누르면 됩니다.

### 자주 나는 에러

| 화면에 뜨는 말 | 무슨 뜻인지 | 어떻게 하면 되는지 |
|---|---|---|
| `EADDRINUSE` 또는 `4123` 관련 에러 | 앱이 이미 켜져 있다는 뜻입니다 | 새로 켤 필요 없이 브라우저에서 http://localhost:4123 을 바로 열어보세요 |
| `claude: command not found` | AI를 실행하는 프로그램을 못 찾았다는 뜻입니다 | 위 0단계로 돌아가 설치를 다시 확인하세요 |
| 사진 자동화가 갑자기 멈춘다 | 브라우저 구성 요소가 아직 준비되지 않았을 수 있습니다 | 앱이 자동으로 설치를 시도합니다. 잠시 뒤 다시 시도해 보세요 |

---

## 2. 네이버에 로그인하기

**네이버에 대신 글을 올리려면 로그인이 한 번 필요합니다.** (보안 때문에 로그인 자체는
자동으로 하지 않습니다 — 화면 위쪽의 **[네이버 로그인]** 버튼을 누르면 새 창이 뜨고,
거기서 평소처럼 직접 로그인하시면 됩니다.)

**"로그인 상태 유지"에 꼭 체크해 주세요.** 체크하지 않으면 몇 시간 뒤 로그인이 풀려서,
읽기는 되는데 글쓰기만 막히는 헷갈리는 상황이 생길 수 있습니다.

로그인이 끝나면 창이 저절로 닫히고, 화면 오른쪽 위 "네이버" 표시에 초록불이 켜집니다.

---

## 3. AI로 사진 만들기 (선택 사항)

사진을 인터넷에서 검색해 가져오는 대신, **AI가 직접 그리게** 할 수도 있습니다. 저작권
걱정이 없다는 장점이 있습니다. **하지 않으셔도 앱은 전부 돌아갑니다** — 사진을 검색해서
가져오거나, 직접 찍은 사진을 써도 됩니다.

하시려면 5분 정도 걸립니다.

1. `env.sample` 파일을 복사해서 `.env.local` 이라는 이름으로 저장하세요.
   ```bash
   cp env.sample .env.local
   ```
   (윈도우는 `copy env.sample .env.local`)
2. 메모장 같은 편집기로 `.env.local` 파일을 열어 `CLOUDFLARE_ACCOUNT_ID`와
   `CLOUDFLARE_API_TOKEN` 값을 채워주세요. 어디서 받는지는 파일 안 설명을 따라가시면 됩니다.
3. **넣은 뒤에는 1단계에서 켜둔 창을 껐다(Ctrl+C) 다시 켜주세요(`npm run dev`).** 열쇠(키)는
   앱을 다시 켜야 반영됩니다.

무료 한도로 하루 40장쯤(품질 설정에 따라 다름) 만들 수 있습니다. 설정 화면에서 지금 설정
기준으로 몇 장 만들 수 있는지 실시간으로 보여줍니다.

---

## 4. 첫 글 만들어보기 — 연습 모드

이제 글을 하나 만들어 볼게요. **기본값이 "연습 모드"라서 실제로 올라가지는 않습니다.**
마음 놓고 눌러보세요.

1. 화면의 세 유형 카드 중 하나를 고르세요.
   - **자동 발굴**: 관심 키워드만 넣으면 AI가 요즘 뜨는 뉴스/블로그를 보고 글감부터 골라 씁니다.
   - **체험단**: 직접 방문/사용한 것처럼 1인칭 후기체로 씁니다. 주제와 핵심 내용을 알려주세요.
   - **브랜딩·전문성**: 전문가 포지셔닝 글을 씁니다.
2. 사진을 어떻게 구할지 고르세요(없음 / 내 사진 / 검색 크롤링 / AI 생성).
3. **[연습으로 만들기]** 를 누르세요.

3~7분쯤 걸립니다. 중간에 브라우저 창이 저절로 열렸다 닫히는데 **건드리지 마세요.** 다 되면
화면에 완성된 글과 사진, 그리고 완성 화면 스크린샷이 보입니다.

---

## 5. 진짜로 올리기 ⚠️

연습으로 만든 글이 마음에 드시면 이제 진짜로 올릴 수 있습니다.

> **여기서부터는 되돌릴 수 없습니다.** 글이 실제 블로그에 올라갑니다.

**처음에는 반드시 비공개로 올려보시길 권합니다.** 나만 볼 수 있어서, 어떻게 나오는지 확인하고
나중에 공개로 바꿀 수 있습니다. (설정의 공개 범위가 기본으로 이미 비공개로 되어 있습니다.)

1. 오른쪽 위 톱니바퀴를 눌러 **설정**을 여세요.
2. **연습 모드**를 꺼주세요.
3. 다시 글 만들기를 누르면 버튼이 **[글 만들고 발행하기]** 로 바뀌어 있습니다. 눌러주세요.

다 되면 실제 올라간 글 주소가 화면에 뜹니다. 눌러서 글과 사진이 제대로 들어갔는지 봐주세요.
테스트로 올린 글이라면 블로그에서 글 오른쪽 위 **[삭제]** 를 눌러 지우셔도 됩니다.

### 안전장치

이 앱은 계정 제재 위험을 줄이기 위한 브레이크를 여러 겹 갖고 있습니다. 전부 설정 화면에서
바꿀 수 있지만, 특별한 이유가 없다면 그대로 두시길 권합니다.

- **연습 모드** — 기본 켜짐. 발행 없이 완성 화면만 저장합니다.
- **전체 중단** — 켜면 무슨 일이 있어도 발행되지 않습니다.
- **하루 발행 수** — 기본 3편까지. (네이버가 정한 값이 아니라 이 앱이 스스로 정한 보수적인
  값입니다. 네이버의 실제 한도는 공개돼 있지 않습니다.)
- **발행 간격** — 기본 30분 이상 띄웁니다.
- **공개 범위** — 기본 비공개.

검색으로 가져온 사진은 AI가 워터마크·초상권을 한 번 걸러내지만, 그래도 저작권 분쟁 소지가
있을 수 있습니다. 상업적으로 쓰실 거라면 AI 생성 사진이 더 안전합니다.

---

## 화면 보는 법

- **맨 위 띠(레일)**: 지금 연습 모드인지 실제 발행 모드인지, 전체 중단이 켜져 있는지를
  색으로 보여줍니다. 초록 = 안전(연습 모드), 주황 = 실제로 올라감/전체 중단.
- **계량기 2개**: 오늘 몇 편 올렸는지, 오늘 AI 사진을 얼마나 만들었는지.
- **최근 작업**: 지금까지 만든 글 목록. 눌러보면 그 글의 진행 상황과 결과가 나옵니다.

## 문제가 생겼을 때

| 화면에 뜨는 말 | 무슨 뜻인지 | 어떻게 하면 되는지 |
|---|---|---|
| 인터넷 연결에 문제가 있어 접속하지 못했습니다 | 네이버·구글에 연결하지 못했습니다 | 인터넷 연결을 확인한 뒤 다시 시도하세요 |
| 오늘 AI 사용량을 다 썼습니다 | Claude 구독의 하루 한도를 다 썼습니다 | 보통 몇 시간 뒤(초기화 시각)에 다시 쓸 수 있습니다 |
| 네이버 로그인이 필요합니다 | 로그인 정보가 없거나 만료됐습니다 | **[네이버 로그인]** 을 다시 누르고, 이번엔 "로그인 상태 유지"를 꼭 체크하세요 |
| AI 사진 생성 열쇠가 없습니다 | Cloudflare 키를 안 넣었습니다 | 3단계를 하거나, 사진 소스를 "검색 크롤링"이나 "없음"으로 바꾸세요 |

이 표에 없는 문제라면, 화면에 뜨는 안내 문장을 그대로 캡처해서 알려주시면 됩니다.

## 알아두실 점

- 이 앱은 **윈도우에서는 아직 실제로 확인되지 않았습니다**(개발·검증은 리눅스/맥 환경에서
  했습니다). 대부분 그대로 동작하도록 만들었지만, 폴더 선택창처럼 윈도우 전용 코드 경로는
  실제 윈도우 환경에서 처음 겪는 문제가 있을 수 있습니다.
- 수집한 뉴스·블로그 자료는 참고용입니다. AI에게 그대로 베끼지 말라고 지시해 두었지만,
  발행 전에 한 번 읽어보시길 권합니다. 브랜딩 글의 숫자·실적은 사용자가 입력한 내용
  안에서만 씁니다.

## (개발자용) 전체 자동 점검

계정 없이 확인할 수 있는 부분을 한 번에 점검하는 명령어입니다. 몇 분 걸리고, Claude 사용량을
씁니다.

```bash
npm run verify
```

`scripts/verify-*.ts` 각각을 따로 실행할 수도 있습니다(`npx tsx scripts/verify-neurons.ts`
같은 식). 네이버 로그인이 있어야 확인할 수 있는 부분(실제 발행, 캡션·서식의 시각적 정확성
등)은 이 점검에 포함돼 있지 않습니다 — 로그인 후 직접 "연습으로 만들기"를 눌러 확인해 주세요.
