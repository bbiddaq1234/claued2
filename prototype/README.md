# 웹 프로토타입 (정적 데모)

`index.html` 하나로 된, 화면 구성과 사용 흐름만 보여주는 정적 데모입니다.

**실제 앱과는 다릅니다** — 네이버 로그인·발행, AI 호출이 전혀 일어나지 않고, 화면에
보이는 글·최근 작업은 전부 미리 넣어둔 예시이거나 버튼을 눌렀을 때 그 자리에서
흉내 낸 결과입니다. 실제로 글을 쓰고 발행하는 프로그램은 저장소 루트의 앱(`app/`,
`lib/` 등, `README.md` 참고)입니다.

## 보는 법

`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 보입니다(별도 설치·서버 필요 없음).
